# API Testing Project – Postman & JavaScript

## Overview
This project demonstrates API testing using Postman and JavaScript. It covers CRUD operations, authentication, environment handling, and automated execution readiness.

## Tech Stack
- Postman
- JavaScript
- Newman
- GitHub

## APIs Covered
- GET Users
- POST Create User
- PUT Update User
- DELETE User
- POST Login

## Features
- JavaScript assertions
- Environment variables
- API key authentication
- Positive and negative test cases

## How to Run
1. Import collection from `collections` folder into Postman
2. Import environment from `environments` folder
3. Add your API key in environment
4. Run collection
